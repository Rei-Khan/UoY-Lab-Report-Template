# Lab Report Template

- `bib.bib`: Empty file. This is where you should write your bibliography.
- `labreport.cls`: A LaTeX class. This defines how the document looks and is not intended to be edited.
- `main.tex`: The LaTeX file to be compiled. This is where you write your report. There's already an outline of which sections to include.

---
If you're unfamiliar with LaTeX, here's how I'd recommend getting setup:
1. Download the files in this repository as a `.zip`, but don't worry about opening them.
2. Make an [Overleaf](https://www.overleaf.com/) account using your UoY Single Sign-On.
3. Make a New Project on Overleaf, but select Import > Existing Project (.zip)
4. You can now have a little look at how LaTeX looks/is written! You might want to make another project and have a play around before you start writing the report.

## Learning Resources
- [LearnLaTeX.org](https://www.learnlatex.org/en/) is provided by the team behind the LaTeX language
- I personally prefer [the resources Overleaf provide](https://www.overleaf.com/learn)
- I've also picked out a few of my favourite pages from this:
  - [Including maths](https://www.overleaf.com/learn/latex/Mathematical_expressions) - although I'd recommend simply using `\[` at the start and `\]` at the end of equations, or dollar symbols `$` around inline maths.
  - [Subscripts and superscripts](https://www.overleaf.com/learn/latex/Subscripts_and_superscripts) - `^` for superscripts and `_` for subscripts, using curly braces `{}` if there are multiple characters affected.
  - [Fractions](https://www.overleaf.com/learn/latex/Fractions_and_Binomials) - just use `\frac{}{}` for fractions, with the numerator in the first set of curly braces and the denominator in the second.
  - [Tables](https://www.overleaf.com/learn/latex/Tables)
  - And finally, my favourite: a [list of Greek letters and maths symbols](https://www.overleaf.com/learn/latex/List_of_Greek_letters_and_math_symbols)!
- There are also [docs for Overleaf](https://docs.overleaf.com/), just in case!

Good luck!
